# Read the documents

A procedure is to be built from this brief:

{brief}

The source documents, relative to the working directory (an empty list when there are none):

{files}

Read every document with `read_file`. Write down, as notes, everything in them that bears on the
brief: the rules and limits (with their numbers), who may decide what, the cases and their
exceptions, the wording a reply must use, the systems or queues work is sent to. Say which file
each note comes from. Leave out what does not bear on the brief. When there are no documents,
say so in one line and note only what the brief itself says.

Answer with `notes`: the notes as one string, a few short lines per document.
